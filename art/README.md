# Art and sound sources

The addon's pixel art and sounds are generated by these scripts, so they can be tweaked and re-made instead of
hand-edited:

- `make_textures.py` - the two block textures (12-frame animations) and the 64x32 card shown in the remote's menu and
  HUD.
- `make_thumbnail.py` - the project thumbnail (`thumbnail.png`, 512x512, used on CurseForge) and the mod's logo in
  the game's mod list.
- `make_sounds.py` - all eleven sounds (one function each; their lengths match the strike's timeline, e.g. the
  countdown is cut to end exactly at touchdown).

They need Python 3 with `numpy` and `Pillow`; the sounds also need `scipy` and `soundfile`
(`pip install numpy pillow scipy soundfile`). Run them from anywhere; they write straight into `src/main/resources`.
